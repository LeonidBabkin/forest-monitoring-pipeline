
# Проект: Мониторинг деградации лесов (Трир / долина Мозеля)

**Район исследования:** Трир и долина Мозеля, Германия (2018–2026)
**Статус проекта:** В разработке (Production pipeline)

## 1. О проекте
Проект представляет собой модульный пайплайн для автоматизированного мониторинга деградации лесного покрова (вырубки, пожары, короед) на основе данных дистанционного зондирования. Основной упор сделан на строгую научную валидацию (по стандартам Olofsson), воспроизводимость и отказоустойчивость вычислений.

**Ключевая особенность архитектуры:** Проект эволюционировал от облачной платформы Google Earth Engine (GEE) к **полностью локальной обработке** на Python (`rasterio`, `numpy`, `scipy`). Это позволяет обойти лимиты GEE на параллельные агрегации, получить полный контроль над памятью и обеспечить прозрачность математики на каждом шаге.

## 2. Архитектура пайплайна (Модули 1-6)

Пайплайн состоит из 6 последовательных модулей, связанных жесткими контрактами данных:

*   **M1. Топографическая коррекция (SCS+C)**
    *   *Задача:* Устранение влияния рельефа (теней) на яркость снимков Sentinel-2.
    *   *Статус:* ✅ **ЗАВЕРШЕН** (Локальная версия, Gate 1 пройден).
    *   *Детали:* [См. документацию модуля](https://github.com/LeonidBabkin/forest-monitoring-pipeline/blob/main/README.md/m1_local/README.md).
*   **M2. Построение годового ряда (QC)**
    *   *Задача:* Сборка медианных композитов NBR за каждый год с контролем качества (маска облаков, количество наблюдений).
    *   *Статус:* 📝 В планах (ТЗ готово).
*   **M3. Обнаружение изменений (LandTrendr)**
    *   *Задача:* Временная сегментация NBR для поиска точек разрыва (год нарушения).
    *   *Статус:* ⚠️ Требует разработки (критический путь).
*   **M4. Классификация (Random Forest)**
    *   *Задача:* Классификация типов нарушений (вырубка, пожар, короед) на основе признаков LandTrendr. Пространственно-блочная кросс-валидация.
    *   *Статус:* 🛠 Код CV готов, требуется сбор обучающих данных.
*   **M5. Оценка точности (Olofsson)**
    *   *Задача:* Математически строгая оценка точности и площади с доверительными интервалами.
    *   *Статус:* 🛠 Движок и генератор выборки готовы, требуется слепая разметка.
*   **M6. Экспорт и поставка**
    *   *Задача:* Экспорт финальной карты в формате Cloud Optimized GeoTIFF (COG) с метаданными.
    *   *Статус:* ✅ Production-код готов.

## 5. Установка и требования к окружению

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/LeonidBabkin/forest-monitoring-pipeline.git
   cd forest-monitoring-pipeline
   ```

2. **Создайте виртуальное окружение (рекомендуется Conda):**
   ```bash
   conda create -n forest_env python=3.10
   conda activate forest_env
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

## 6. Требования к данным
Проект использует данные Sentinel-2 Level-2A (Surface Reflectance) и Цифровую Модель Рельефа (DGM10).
*   Подробная инструкция по скачиванию данных, конвертации форматов (JP2 -> TIFF) и репроецированию находится в [README модуля M1]((https://github.com/LeonidBabkin/forest-monitoring-pipeline/blob/main/README.md/m1_local/README.md)).

## 7. Запуск модулей
Каждый модуль автономен и запускается из своей директории.

**Для запуска Модуля 1:**
```bash
cd m1_local
python run_m1_local.py
```

## 8. Тестирование
Для запуска unit-тестов перейдите в папку модуля и вызовите `pytest`:
```bash
cd m1_local
pytest tests/ -v
```
