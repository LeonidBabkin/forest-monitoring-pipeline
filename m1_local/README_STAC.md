# Способ 2: Облачная обработка через STAC (Sentinel-2 L2A)

Этот скрипт (`fetch_data_stac.py`) предназначен для автоматического поиска, скачивания и топографической коррекции сцен Sentinel-2 из облачного каталога **Microsoft Planetary Computer** с использованием протокола STAC.

## 📌 Зачем это нужно?
Вручную скачивать десятки сцен за несколько лет — долго и чревато ошибками. Этот скрипт делает всё сам: он ищет сцены за нужные месяцы, фильтрует их по облачности, вырезает только ваш район исследования (AOI), перепроецирует его в нужную систему координат и передает в единое математическое ядро SCS+C.

## 🚀 Как запустить

### 1. Требования к окружению
Убедитесь, что у вас установлены библиотеки для работы с облачными данными и Dask (для ленивой загрузки):
```bash
mamba install -c conda-forge pystac-client planetary-computer rioxarray dask
```
*(Или используйте `pip install pystac-client planetary-computer rioxarray dask`)*.

### 2. Настройка параметров поиска
Откройте `fetch_data_stac.py` и в самом низу (в блоке `if __name__ == "__main__":`) настройте интересующий вас период:
```python
results = fetch_data_stac(
    cfg,
    years=[2019, 2020],           # Список лет
    max_cloud=15.0,               # Максимальная облачность сцены (%)
    max_scenes_per_year=5,        # Сколько успешных сцен нужно на каждый год
    months=[6, 7, 8],             # Летние месяцы (июнь, июль, август)
    target_epsg=25832,            # Целевая проекция (UTM 32N)
)
```

### 3. Запуск
Выполните в терминале (из папки `m1_local`):
```bash
python fetch_data_stac.py
```

## ⚙️ Как это работает под капотом (Логика скрипта)

1. **Поиск (STAC Search):** Скрипт делает запрос к Planetary Computer, ищет сцены `sentinel-2-l2a` в границах вашего AOI (из `config.yaml`) за указанные годы. Фильтрует их по облачности и оставляет только нужные месяцы.
2. **Извлечение метаданных:** В отличие от локального метода, здесь не нужен XML-файл. Углы солнца (`s2:mean_solar_zenith`) и радиометрическая поправка (`s2:boa_add_offset = -1000`) считываются прямо из JSON-свойств сцены (STAC Item).
3. **Умная загрузка (Dask + clip_box):** Скрипт сначала обрезает (клипает) нужный кусочек снимка в родной проекции сцены, и **только потом** перепроецирует его. Это позволяет Dask скачивать из облака только маленький кусок (ваш AOI), а не всю сцену (10000x10000 пикселей). Это спасает от зависаний и экономит память.
4. **Вызов ядра:** Обрезанные и подготовленные каналы временно сохраняются в `data/raw/`, после чего вызывается функция `process_scene` (из `run_m1_local.py`), которая выполняет SCS+C.
5. **Очистка и Аудит:** Если сцена не прошла калибровку (`scsc_processed = 0`, например, из-за плохой регрессии), её файлы удаляются, чтобы не засорять диск. Успешные сцены записываются в отчет `m1_stac_audit.csv`.

## 📂 Результаты работы
*   В папке `data/output/` появятся откалиброванные файлы `{scene_id}_B08_corr.tif` и `{scene_id}_B12_corr.tif`.
*   В корне папки появится файл **`m1_stac_audit.csv`** — таблица с результатами калибровки (значения C, корреляция Пирсона, флаг успеха).

## ⚠️ Известные ограничения
*   **Ошибка 403 (Forbidden):** Может возникнуть, если токен доступа к Planetary Computer истечет во время обработки. Чтобы этого избежать, код использует `clip_box` до перепроецирования (обработка занимает секунды). Если ошибка всё же появилась — просто запустите скрипт заново.
*   **Зависимость от интернета:** В отличие от локального метода, этот скрипт требует стабильного подключения к сети.
